NepseBot is an AI-powered trading assistant designed specifically for Nepal Stock Exchange investors, enabling instant access to domain-specific knowledge on SEBON regulations, tax structures, and market data through a secure local web interface built with Python, Flask, and Groq's Llama 3.3 API. To use it, simply clone the repository, install dependencies via `pip install -r requirements.txt`, configure your `GROQ_API_KEY` and `FLASK_SECRET_KEY` in the `.env` file, and run `python app.py` to launch the server at `http://127.0.0.1:5000` where you can chat naturally about stock prices, settlement cycles, or trading rules while the system maintains conversation context and fetches live market insights. This educational tool leverages a modular architecture with dedicated services for AI reasoning, data fetching, and session management to provide fast, accurate financial information without page reloads, though users should verify all data with certified brokers before making investment decisions.
